# 📚 Data Structures in Java

Welcome to my **Data Structures in Java** repository!

This repository contains simple Java programs that help me learn and practise Data Structures and Algorithms as a BSc IT undergraduate.

## 🚀 Topics Covered

- **Arrays** – Insertion, deletion, and traversal
- **Searching** – Linear Search and Binary Search
- **Linked Lists** – Basic linked list operations
- **Stacks** – Stack using arrays and linked lists
- **Queues** – Queue and Circular Queue
- **Trees** – Binary Tree and Binary Search Tree
- **Tree Traversal** – Preorder, Inorder, and Postorder

## 🛠️ Technologies Used

- Java
- JDK (Java Development Kit)
- Visual Studio Code
- Git and GitHub

## ▶️ How to Run

**1. Clone this repository**

```bash
git clone https://github.com/farisjm/Data-Structure.git
```

**2. Open the project folder**

```bash
cd Data-Structure
```

**3. Compile a Java program**

```bash
javac TreeTraversal.java
```

**4. Run the program**

```bash
java TreeTraversal
```

Replace `TreeTraversal` with the appropriate class name for the program you want to run.

> **Note:** Run individual programs separately. Some files may contain classes with the same name, so compiling all files together may cause errors.
